# D2D-Nav project page

Static project page for *D2D-Nav: Benchmarking Door-to-Door Navigation on Planned Routes* (Tsinghua University and QUORRA).

No build step. GitHub Pages serves it from the repository root: Settings, Pages, Deploy from a branch, `main`, `/ (root)`.

- `index.html`: the page
- `static/`: styles, script, fonts, figures, videos, and the data for the ink picture at the top
- `gallery/`: frames of the eighteen cases only DeRoute passes

Fonts: Lora (SIL Open Font License 1.1) and DejaVu Sans Mono (Bitstream Vera license), subset to Latin.
